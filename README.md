# Effect Video

Turn still photos into short AI videos with ready-made effect templates.

[Visit Effect Video](https://effect.video/)

## Disclosure and purpose

This repository is the official public directory for Effect Video. It introduces the website and links to its live pages; it is not an independent review. The application source is not published here. A public GitHub listing here does not guarantee search-engine indexing, ranking, or backlink value.

## What it does

There is no editing timeline. Upload photo(s), add audio when a template requires it, choose a template, generate, and download. You can view examples for free. Generations use credits; verified accounts can claim welcome credits once, but a credit balance does not guarantee a free video at every setting. Reserved credits are returned for failed generations. Photos and videos are not used to train AI models. Photos are deleted after processing, with queue and comparison exceptions noted by the site; videos are kept for 7 days. See [plans and credit packs](https://effect.video/pricing).

## How to use and key pages

| Page | What you can do |
| --- | --- |
| [Effects gallery](https://effect.video/effects) | Browse published templates, including dance, duets, hugs, anime transformations, and lip sync. |
| [Hotel Lobby](https://effect.video/effects/hotel-lobby) | Create a duet from one or two photos. The first replaces the main person; the optional second replaces another. Original audio is preserved. The page specifies a 10-second, 16:9 MP4 at 768p. |
| [AI Dance](https://effect.video/effects/ai-dance) | Turn a full-body photo into a dance video using the same one- or two-photo replacement pattern. Original audio is preserved. The page specifies a 5-second, 9:16 MP4 at 768p. |
| [AI Lip Sync](https://effect.video/effects/ai-lip-sync) | Use one front-facing adult portrait (JPEG or PNG, up to 5 MB) and one MP3 or WAV clip (up to 15 seconds and 5 MB). Output is MP4, follows portrait dimensions, and matches audio length up to 15 seconds. |

## Limits and privacy

Template inputs and output formats vary, so check the individual page before generating. Read the site's [privacy policy](https://effect.video/privacy) for current details.
